# Checklist de Rastreamento

1. Atualizar os checkboxes do arquivo de tarefa atual que correspondem às subtarefas concluídas.
2. Alterar o status da tarefa para `completed` apenas após implementação, validação (`npm run lint && npm run build`) e revisão automática completas.
3. Atualizar a entrada em `tasks.md` mestre que aponta para o arquivo de tarefa atual.
4. Reler a especificação da tarefa e os documentos do PRD antes de marcar como concluída.
5. Seguir o modo de commit do chamador ao decidir se arquivos de rastreamento pertencem a um commit.
