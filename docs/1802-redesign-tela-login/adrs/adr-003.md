# ADR-003: "Esqueci minha senha" apenas visual no MVP

## Status

Accepted

## Data

2026-08-08

## Contexto

O formulário deve incluir o link "Esqueci minha senha" (elemento esperado em qualquer tela de login). Hoje o projeto **não possui** fluxo de reset de senha nem rota de recuperação — apenas supabase.auth.signInWithPassword. Implementar o fluxo completo (email de reset, rota de redefinição, tratamento de vínculos de sessão) expandiria bastante o escopo do MVP.

## Decisão

No MVP, o link **"Esqueci minha senha" é apenas visual (placeholder)**: aparece no formulário, mas não dispara fluxo real. Nenhuma rota nova, nenhum e-mail, nenhuma mudança de auth. O fluxo de recuperação real fica **fora de escopo** e deve ser cobertado em uma iniciativa futura.

## Alternativas Consideradas

### Alternativa 1: Implementar fluxo real de reset

- **Descrição**: link dispara `auth.resetPasswordForEmail` do Supabase + rota `/reset-password`.
- **Prós**: funcionalidade completa e esperada em produção.
- **Contras**: escopo maior do MVP; exige telemetria/UX de email e rota segura de redefinição.
- **Por que foi rejeitado**: o usuário escolheu explicitamente "somente visual (placeholder)" no MVP.

### Alternativa 2: Ocultar o link

- **Descrição**: não mostrar o link.
- **Prós**: sem prometer o que não funciona.
- **Contras**: tela de login sem caminho de recuperação parece truncada para usuários que esquecem a senha.
- **Por que foi rejeitado**: o usuário pediu o link no formulário (elemento padrão), demonstrando preferência pelo placeholder.

## Consequências

### Positivas

- Formulário com a parafernália visual de produto maduro sem custo de implementação.
- MVP com escopo enxuto.

### Negativas

- Usuários que clicarem no link não terão ação — risco de confusão/frustração se a intenção não for sinalizada.

### Riscos

- Entendimento errado: recomendar no PRD um aviso explícito (tooltip/disabled ou comportamento neutro) para não induzir a ação sem efeito.

## Notas de Implementação

- Manter o link acessível (Âncora), com `aria-disabled` ou comportamento neutro (sem navegação) para evitar fratura de link.
- Registrar item de backlog futuro: fluxo real de recuperação de senha.
